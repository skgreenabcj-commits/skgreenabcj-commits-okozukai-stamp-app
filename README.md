# おこづかいスタンプアプリ 📱✨

幼児向けのお小遣い管理Webアプリケーションです。毎日の「おべんきょう」「おてつだい」「よいこ」の活動にスタンプを押して、週ごとのお小遣いを計算します。

## 🎯 プロジェクト概要

お子様が楽しみながら良い習慣を身につけ、お小遣いの仕組みを学べるアプリです。

### 主な特徴

- 👶 **幼児向けUI**: 全てひらがな表記で大きく見やすいデザイン
- 📱 **iPhone Safari対応**: タッチ操作に最適化
- 📊 **週単位管理**: 月曜日から日曜日までの週単位でスタンプを集計
- 💰 **自動計算**: スタンプ数×単価で週のお小遣いを計算
- 🏆 **達成バッジ**: 区分ごとに週10個達成で50円ボーナス！
- 🗑️ **スタンプ削除**: 長押しで削除モード起動
- ⚙️ **設定画面**: 名前・単価・スタンプのカスタマイズ可能
- 💾 **バックアップ機能**: 自動バックアップ（デイリー）+ 手動エクスポート/インポート
- 📈 **履歴管理**: 過去の週ごとのお小遣いを棒グラフで可視化
- 🎨 **カスタムスタンプ**: 14種類から6つを選択可能（男の子向け・女の子向けも用意）

## 🚀 現在実装済みの機能

### ✅ ページ1: 今週のスタンプ

- **週の表示**: 「●がつ●にちのしゅう」形式で表示
- **スタンプパレット**: 有効化した6種類のスタンプを表示
- **スタンプ表**:
  - 7日間（月曜〜日曜）× 3区分（おべんきょう/おてつだい/よいこ）
  - 各区分で1日最大2つまでスタンプ可能
  - 今日の日付をハイライト表示
  - 長押しで削除モード起動
- **達成バッジ表示**: 
  - 区分ごとに週10個以上でバッジ表示
  - バッジ1つにつき50円のボーナス
- **週の集計**:
  - 週の合計スタンプ数
  - 今週のお小遣い（100円単位）
  - 達成ボーナス（区分ごと50円）
  - 翌週への持ち越し額（100円未満の端数）

### ✅ ページ2: 累積

- **累積給付額**: これまでに給付したお小遣いの合計を大きく表示
- **週ごとのグラフ**: Chart.jsを使った棒グラフで最新10週分を表示
- **履歴リスト**: 週ごとのスタンプ数とお小遣い額を一覧表示

### ✅ ページ3: 設定

- **基本設定**:
  - 子供の名前変更
  - スタンプ単価変更（デフォルト10円）
- **達成バッジ設定**:
  - バッジ獲得の閾値設定（デフォルト10個）
  - バッジ1つあたりのボーナス額設定（デフォルト50円）
- **スタンプ設定**:
  - 14種類のスタンプから6つを選択
  - タップで有効/無効を切り替え
  - **基本**: 👸 プリンセス、🌟 きらきら、🎉 おいわい、🏆 トロフィー
  - **動物**: 🐱 ねこ、🦋 ちょうちょ
  - **自然**: 🌈 にじ、🌸 おはな、🏅 メダル
  - **乗り物**: 🚗 くるま、🚂 でんしゃ、🚜 はたらくくるま
  - **女の子向け**: 👑 おうかん、💝 はーと
- **バックアップと復元**:
  - 自動バックアップ（デイリー・LocalStorage）
  - 手動バックアップ（JSONファイルダウンロード）
  - データ復元（JSONファイルアップロード）
  - 自動バックアップからの復元
- **データリセット**:
  - 全データを削除する機能（確認ダイアログ付き）

### ✅ お小遣い計算ロジック

1. 週のスタンプ合計 × 単価 = 基本金額
2. 達成ボーナスを加算（区分ごと週10個以上で50円）
3. 前週からの持ち越し額を加算
4. 100円単位で給付（例: 285円 → 200円給付）
5. 100円未満の端数は翌週に持ち越し（85円持ち越し）

### ✅ 達成バッジシステム

- **条件**: 各区分（おべんきょう/おてつだい/よいこ）で週に設定した数以上のスタンプ（デフォルト10個）
- **報酬**: 1区分達成につき設定したボーナス額（デフォルト50円）
- **最大**: 3区分すべて達成で最大ボーナス（デフォルト設定で150円）
- **表示**: 達成した区分に🏆マークと金額を表示
- **カスタマイズ可能**: 設定画面で閾値とボーナス額を変更可能

### ✅ スタンプ削除機能

- **起動方法**: スタンプがあるマスを長押し（約0.8秒）
- **削除モード**: 画面上部に赤いバナーが表示
- **削除方法**: 削除したい区分のマスをタップ
- **確認**: 削除前に確認ダイアログ表示
- **終了**: 「もどる」ボタンで通常モードに戻る

### データベース
RESTful Table APIを使用した5つのテーブル:

#### 1. `stamps` テーブル
```
- id: レコードID
- week_start: 週の開始日（月曜日）
- date: スタンプを押した日付
- category: 区分（おべんきょう/おてつだい/よいこ）
- stamp_type: スタンプの種類（絵文字）
- stamp_count: スタンプの個数
```

#### 2. `weekly_history` テーブル
```
- id: レコードID
- week_start: 週の開始日
- week_label: 週のラベル（●がつ●にちのしゅう）
- total_stamps: 週の合計スタンプ数
- allowance_paid: 給付したお小遣い
- carryover: 翌週への持ち越し額
```

#### 3. `settings` テーブル
```
- id: レコードID
- child_name: 子供の名前
- stamp_unit_price: スタンプ単価（デフォルト10円）
- total_paid: 累積給付額
```

#### 4. `custom_stamps` テーブル（新規追加）
```
- id: レコードID
- stamp_name: スタンプ名
- stamp_emoji: スタンプ絵文字
- stamp_url: カスタム画像URL（オプション）
- is_active: 有効/無効
```

#### 5. `achievements` テーブル（新規追加）
```
- id: レコードID
- week_start: 週の開始日
- category: 達成した区分
- stamp_count: スタンプ数
- bonus_amount: ボーナス額
```

## 🔄 使い方

### スタンプを押す
1. 「きょうのスタンプ」タブを開く
2. 曜日と区分（おべんきょう/おてつだい/よいこ）のマスをタップ
3. 好きなスタンプを選んでタップ
4. スタンプが押される（1日1区分につき最大2つまで）

### スタンプを削除する
1. 削除したいマスを長押し（約0.8秒）
2. 削除モードが起動（赤いバナーが表示）
3. 削除したい区分のマスをタップ
4. 確認ダイアログで「OK」を選択
5. 「もどる」ボタンで通常モードに戻る

### 達成バッジを獲得する
1. 1つの区分で週に設定した数以上のスタンプを集める（デフォルト10個）
2. 自動的に🏆バッジが表示される
3. お小遣い計算時に設定したボーナスが加算される（デフォルト50円）

### 設定を変更する
1. 「せってい」タブを開く
2. **なまえ**: 子供の名前を入力
3. **スタンプ1このねだん**: 単価を変更（デフォルト10円）
4. **バッジをもらえるスタンプのかず**: 達成閾値を変更（デフォルト10個）
5. **バッジ1このごほうび**: ボーナス額を変更（デフォルト50円）
6. **スタンプせってい**: 使いたい6個のスタンプを選択
7. 「ほぞんする」ボタンをタップ

### 履歴を見る
1. 「るいせき」タブを開く
2. 累積給付額と週ごとのグラフを確認
3. 下にスクロールして履歴リストを見る

### バックアップを取る
1. 「せってい」タブを開く
2. 「データのバックアップ」セクションを確認
3. **3つの方法から選べます**:

#### 方法1: ファイルでバックアップ（推奨）
   - 「💾 ファイルでバックアップ」をタップ
   - `okozukai-backup.json`（固定ファイル名）がダウンロードされる
   - iCloud DriveやGoogleドライブに保存
   - **メリット**: 管理が簡単、同じファイル名で上書き保存

#### 方法2: データをコピー（Google Drive向け）
   - 「📋 データをコピー」をタップ
   - データがクリップボードにコピーされる
   - Google Driveを開く
   - 新しいテキストファイルを作成
   - 貼り付け（ペースト）
   - 「okozukai-backup.txt」として保存
   - **メリット**: Google Driveに直接保存可能

#### 方法3: QRコードでバックアップ（スマホ間移行用）
   - 「📱 QRコードでバックアップ」をタップ
   - QRコードが表示される
   - 別のスマホでQRコードをスキャン
   - **メリット**: 機種変更時に便利
   - **注意**: データ量が多いと読み取りにくい場合あり

4. **自動バックアップ**:
   - 毎日1回自動で実行される（LocalStorageに保存）
   - 最終バックアップ日時を確認できる

### データを復元する
1. 「せってい」タブを開く
2. 「データのふくげん」セクションへ
3. **3つの方法から選べます**:

#### 方法1: ファイルから復元
   - 「💾 ファイルからふくげん」をタップ
   - 保存した`okozukai-backup.json`を選択

#### 方法2: コピーしたデータから復元
   - 「📋 コピーしたデータからふくげん」をタップ
   - Google Driveのテキストファイルを開く
   - 全て選択してコピー
   - アプリに戻って貼り付け

#### 方法3: 自動バックアップから復元
   - 「🔄 じどうバックアップからふくげん」をタップ
   - LocalStorageに保存されたバックアップから復元
   - **注意**: 同じデバイス・同じブラウザのみ有効

### 5. バックアップ・復元システム（強化版）

#### 自動バックアップ（デイリー）
- 毎日1回、自動的にLocalStorageにバックアップ
- 前日のバックアップを上書き
- ブラウザ内に保存（同じブラウザ・デバイス内で有効）
- 最終バックアップ日時を表示

#### 手動バックアップ（3つの方法）

##### 1. ファイルでバックアップ（推奨）
- **固定ファイル名**: `okozukai-backup.json`
- 同じファイル名で上書き保存されるため管理が簡単
- iCloud DriveやGoogle Driveへの保存を推奨
- **使い方**:
  1. 「💾 ファイルでバックアップ」をタップ
  2. ダウンロードフォルダに保存される
  3. クラウドストレージに移動

##### 2. データをコピー（Google Drive向け）
- **クリップボードにコピー**: JSON形式のテキストデータ
- Google Driveに直接テキストファイルとして保存可能
- **使い方**:
  1. 「📋 データをコピー」をタップ
  2. Google Driveを開く
  3. 新しいテキストファイルを作成
  4. 貼り付け（Ctrl+V / ⌘+V）
  5. 「okozukai-backup.txt」として保存

##### 3. QRコードでバックアップ（スマホ間移行用）
- **QRコード生成**: データをQRコードに変換
- スマホのカメラでスキャンするだけで移行可能
- **使い方**:
  1. 「📱 QRコードでバックアップ」をタップ
  2. QRコードが表示される
  3. 別のスマホでQRコードをスキャン
  4. データが自動的に復元される
- **注意**: データ量が多い（スタンプが多い）と読み取りにくい場合あり

#### データ復元（3つの方法）

##### 1. ファイルから復元
- `okozukai-backup.json`を選択
- 既存データを完全に上書き（確認ダイアログ付き）

##### 2. コピーしたデータから復元
- Google Driveのテキストファイルからコピー＆ペースト
- クリップボード経由で復元

##### 3. 自動バックアップから復元
- LocalStorageに保存された自動バックアップから復元
- 同じブラウザ・デバイス内でのみ有効

#### 対応シナリオ
- ✅ スマホの機種変更（QRコード/ファイル/コピーで移行）
- ✅ ブラウザデータの削除（ファイル/コピーから復元）
- ✅ アプリの誤操作（自動バックアップから復元）
- ✅ 複数デバイスでの共有（Google Drive経由）

### よくある問題と解決方法

1. **スタンプが押せない**: 
   - ブラウザのJavaScript設定を確認
   - 1日1区分2個の制限を確認

2. **データが表示されない**: 
   - ネットワーク接続を確認
   - ページをリロード

3. **グラフが表示されない**: 
   - Chart.jsの読み込みを確認
   - ブラウザキャッシュをクリア

4. **長押しが反応しない**:
   - 約0.8秒しっかり押し続ける
   - スタンプがあるマスのみ反応

5. **達成バッジが表示されない**:
   - 週の途中でスタンプ数が設定した閾値以上か確認
   - 設定画面でバッジ設定を確認
   - ページをリロードして再計算

6. **設定画面でスタンプ選択肢が表示されない（修正済み）**:
   - ページをリロードすると自動的に初期スタンプデータが作成されます
   - 修正により、デプロイ環境でも正常に動作します

```
- id: レコードID
- week_start: 週の開始日
- week_label: 週のラベル（●がつ●にちのしゅう）
- total_stamps: 週の合計スタンプ数
- allowance_paid: 給付したお小遣い
- carryover: 翌週への持ち越し額
```

#### 3. `settings` テーブル
```
- id: レコードID
- child_name: 子供の名前
- stamp_unit_price: スタンプ単価（デフォルト10円）
- total_paid: 累積給付額
```
